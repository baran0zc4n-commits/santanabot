# santanabot

Vencord userplugin koleksiyonu.

## Pluginler

### [AutoUnmuteDeaf](./autoUnmuteDeaf)

Sunucu tarafindan atilan mute ve deaf islemlerini otomatik olarak kaldiran bir Vencord userplugin'i.

## Kurulum

1. Vencord'u kaynak koddan kurun ([rehber](https://github.com/Vendicated/Vencord))
2. Bu repo'daki plugin klasorlerini `src/userplugins/` dizinine kopyalayin
3. `pnpm build && pnpm inject` ile derleyip enjekte edin
4. Discord'u yeniden baslatin ve plugin'leri aktif edin
